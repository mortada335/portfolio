# Full-Stack Developer Portfolio

A professional portfolio built with [Next.js](https://nextjs.org/), [React](https://react.dev/), and [Tailwind CSS](https://tailwindcss.com/) to showcase full-stack development skills, featured projects, technical experience, and contact information.

## Features

- **Modern UI:** Responsive design using Tailwind CSS and custom components.
- **Project Showcase:** Highlight selected projects with code snippets and live demos.
- **Skills & Experience:** Visualize technical skills and work history.
- **Contact Form:** Easy way for visitors to get in touch.
- **Analytics:** Track page views and user interactions.
- **Dark Mode:** Seamless theme switching.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- [pnpm](https://pnpm.io/) or [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

pnpm install
# or
